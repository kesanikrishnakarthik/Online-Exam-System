Core Technical Architecture

Designed to satisfy strict academic compliance, security isolation, and DevOps operational standards.

🏢

Multi-Tenant Data Isolation

Partitioned by institutional collegeCode. Students and faculty of College A are strictly segregated from College B via JPA repository isolation and Firestore security rules.

🛡️

Strict 3-Attempt Exam Policy

Every student is strictly capped at three attempts per exam. Quotas are validated server-side using atomic repository queries before exam initiation to block duplicate attempts.

👁️

Anti-Cheating Integrity Monitor

Active JavaScript proctoring tracks tab switching, window defocusing, and fullscreen exits. Strikes trigger immediate student warnings and auto-finalize exams upon 3 violations.

🔥

Cloud Firestore Live Sync

Integrated with Google Firebase project online-exams-98fa6 for real-time document synchronization, live exam timers, attempt auditing, and cross-platform verification.

📊

Faculty Question Bank & CSV Export

Intuitive exam authoring, automated grading, instant candidate result computation, and institutional CSV score export segregated by college department.

🚀

Automated DevOps CI/CD

Engineered with Eclipse Temurin 25, multi-stage Docker containerization, declarative Jenkinsfile CI/CD pipelines, and zero-fork JUnit surefire test suites.
