Institutional Platform Architecture

Built with enterprise-grade standards for students, faculty, and administrators.

🛡️

Strict 3-Attempt Limit

Every student is strictly limited to three examination attempts per test. Quotas are validated server-side with atomic transaction checks to prevent duplicate submissions.

👁️

Browser Integrity Monitoring

Monitors tab switching, window defocusing, and fullscreen exit. Features configurable warning modals and automatic examination finalization upon reaching 3 violations.

🔥

Cloud Firestore Integration

Integrated with Google Firebase project online-exams-98fa6 for real-time document synchronization, attempt auditing, and secure role-based rules.

🚀

DevOps CI/CD Automation

Complete deployment pipeline managed via Git version control, Jenkinsfile automation, and multi-stage Docker containerization on Eclipse Temurin 21.
